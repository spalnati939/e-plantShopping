# e-plantShopping

Paradise Nursery is a React-based e-commerce web application for browsing and purchasing houseplants. The app lets users explore a catalog of plants, add items to a shopping cart, adjust quantities, and view a running total — all built with React and Redux for state management.

## Features
- Browse a landing page and view plant products by category
- Add plants to the shopping cart
- Increase, decrease, or remove items from the cart
- View total cost of items in the cart
- Simple, responsive UI styled with CSS

## Tech Stack
- React (Vite)
- Redux Toolkit
- CSS

## Getting Started
1. Clone the repository:
   ```
   git clone https://github.com/spalnati939/e-plantShopping.git
   ```
2. Install dependencies:
   ```
   npm install
   ```
3. Run the development server:
   ```
   npm run dev
   ```
